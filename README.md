## 🎯 Цель и философия

**Главная цель:** Написать полноценный 3D RTS движок с гибридной навигацией и тактической глубиной

**Образовательная философия:**
- Понимание КАЖДОГО слоя абстракции
- От простого к сложному через рефакторинг
- Data-oriented design с первого дня
- Сначала геймплей, потом графика

## 🛠️ Технологический стек

### Базовый стек
- **Язык:** C++17 → C++20
- **Сборка:** CMake + vcpkg ✅
- **Тесты:** Catch2 → GoogleTest ✅
- **Профайлинг:** RenderDoc, Nsight, VS Profiler
- **Отладка:** GDB/LLDB, Memory Sanitizers

### Графический стек (эволюционный путь)
1. **Фаза 1:** SDL2 + Примитивы ✅
2. **Фаза 2:** OpenGL 3.3 + Спрайты
3. **Фаза 3:** bgfx (мульти-API)  
4. **Фаза 4:** Vulkan/D3D12 + Продвинутый 3D

### Сетевой стек
- **Transport:** ENet (reliable UDP)
- **Сериализация:** protobuf/flatbuffers
- **Скриптование:** Lua/Sol2 для AI
